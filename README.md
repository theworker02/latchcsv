# latchcsv

Latch config/csv key checks for twelve-factor services.

**Site:** https://theworker02.github.io/latchcsv/

## Install / run

```bash
git clone https://github.com/theworker02/latchcsv.git
cd latchcsv
node src/cli.js
node --test
```
